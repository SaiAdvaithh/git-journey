# Git Learning Repository 

## Purpose

This repository is created to practice and understand Git commands, workflows, and version control concepts.

---

## ⚡ Commands Practiced

```bash
git config --global user.name "your_name"   # Set username globally
git config --global user.email "your_email" # Set email globally

git config --local user.email "your_email" # Set email locally
git config --local user.name "your_name"   # Set username locally

git init              # Initialize a new repository
git clone <url>       # Clone a repository from GitHub

git status            # Check current changes
git add .             # Add all files to staging area
git commit -m "msg"   # Save changes with message

git push origin main  # Push code to GitHub
git pull origin main  # Pull latest changes

git log                                            # View commit history
git diff <mention commit id1 and commit id2 >      # Compare changes between commits

git branch            # List branches
git branch <name>     # Create new branch

git checkout <name>   # Switch branch
git switch <name>     # Alternative to checkout

git merge <branch>    # Merge branches

git stash             # Temporarily save changes
git rebase <branch>   # Reapply commits on another branch
```

---

## 🧠 What I Learned

* How Git tracks changes in files
* Difference between staging and committing
* How to push and pull from GitHub
* Branching and merging workflow
* Comparing commits using `git diff`
* Managing versions effectively
